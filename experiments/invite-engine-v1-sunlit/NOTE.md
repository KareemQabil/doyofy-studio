# Experiment — invite-engine v1 ("Sunlit Architectural Botanical")

**Isolated. Not part of the product.**

This is the modular engine built earlier in this project. Its default replaced the canonical Studio pairing with a new standalone composition (Sunlit Architectural Botanical), which is the class of mistake the production brief forbids. Only the source is kept here, for reference. Its generated assets are not copied.

Ideas re-implemented under the Studio contract in `/src`:

- the registry contract;
- quality tiers;
- the audio event engine;
- RSVP adapters;
- stage-fit camera framing;
- the build/serve tooling.

The Sunlit scene itself is **not** ported. It could become an additional scene renderer later, but only behind the Studio's switcher, never as the default.
