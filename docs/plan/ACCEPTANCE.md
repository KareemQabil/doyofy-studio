# سيناريوهات القبول المقترحة

**مواصفات لم تُنفذ اختبارات جديدة لها في هذه الدفعة.** حالات التحقق القديمة لا تُحسب نجاحًا لميزات الطعام والهدايا غير الموجودة بعد. عند التنفيذ يوثق الاختبار والإصدار والجهاز والنتيجة.

## مصفوفة الأجهزة والأدلة

- iOS Safari وAndroid Chrome: هاتف صغير وكبير، مع touch حقيقي؛ تابلت لمس حقيقي أيضًا لأن المرجع استخدمه.
- Desktop Chrome/Firefox أو Safari المتاح: mouse/trackpad/keyboard، viewport عريض وضيق.
- reduced-motion وsave-data/coarse pointer وWebGL fallback حسب البيئة؛ static fallback يُراجع بصريًا.
- أول مرور على رحلة تخرج كاملة، ثم اسمين طويلين لزفاف، برنامج مؤتمر طويل، ورابط ميلاد عام بلا parties.
- مراجعة starter/content أساسية لكل المناسبات الـ13؛ لا يلزم تكرار اختبار الحفظ نفسه على كل لون.

أدلة الإغلاق: نتائج logic/DOM/contract، ثم browser end-to-end، ثم device/visual/قياسات عند انطباقها. route mounting ليس screenshot QA، وفيديو قديم لا يثبت البناء الجديد. توثق الحالات التي تعذر اختبارها بدل وسمها passed.
