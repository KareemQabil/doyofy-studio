# حالة المصدر عند النقل

**مرجع:** Sites v9، commit `a83069f2fb2c21a1957a78110c7d479b9eac39e7`. تم التأكد في 25 أكتوبر 2026 أن Site ما زال عند v9. لا تثبت أسماء تسجيلات واتساب رقم البناء الذي صُوّر فيها.

## ما نُقل

كود التطبيق والخدمات والقوالب والمحرك، جميع `public/assets`، design-source، studio-design-book، backend المعد سابقًا، الاختبارات وأدوات البناء، وسجلات الأصول والتراخيص. لم يُضف ترخيص جديد أو يُغير جمهور الريبو الذي أنشأه المالك عامًا.

المستبعد من نسخة النقل: node_modules وdist، هوية استضافة Sites، credentials محلية، لقطات QA المولدة، وتسجيلات واتساب والتفريغ الخام. هذه ليست تبعيات لازمة لتشغيل المشروع. plan docs تتضمن traceability بصياغة منتج دون أسماء المشاركين أو تسجيلاتهم.

## حالة التنفيذ

- 13 مناسبة، 28 وجه بطاقة، 86 preset، 9 مظاهر منصة في الكتالوج.
- التشغيل الحالي mock في المتصفح؛ المصادقة واشتراك البيانات بين الأجهزة والإرسال والكاميرا الحقيقية غير مفعلة بمجرد نقل الريبو.
- توجد remote adapters وSQL واختبارات لها؛ لم تُفعّل أو تُعدل في هذه الدفعة.
- تم تحديث README الرئيسي ليصف الواقع، والقديم محفوظ في `docs/LEGACY_README.md`.
- بعض الوثائق القديمة تذكر أعدادًا أو حالات استضافة بتاريخها؛ لا تؤخذ كفحص حالي لحسابات Vercel/Supabase. لا تُستخدم موارد مشاريع أخرى لإكمال ضيوفي.

## ما تحقق في نسخة النقل

`npm run build` نجح، و`npm run assets:shipped:check` أكد 140/140 مرجعًا موجودًا، والخطوط self-hosted. Git tree لدفعة المصدر المكونة من 737 ملفًا تطابقت تمامًا مع النسخة المحلية: `08741bcdea40dd4b662362a70155ed63b8408fb0`. commit النقل على GitHub هو `951f17d8aaf4128a54fe49a581c55e4649a50a9b`. تُضاف وثائق الخطة في commit مستقل حتى يبقى فرق التخطيط عن المصدر واضحًا.

`SOURCE_SNAPSHOT.json` يسجل ملفات دفعة المصدر الأصلية قبل إضافة plan docs وروابطها، وليس manifest يتغير تلقائيًا مع كل commit لاحق.

في التدقيق السابق لنفس كود التطبيق: TypeScript ناجح، تغطية 68 unit tests عبر التشغيل العام وإعادة تشغيل اختبارات الخدمات الثلاث منفردة، و42 DOM behavior و84 route mounts. هذه نتائج منطق/DOM ولا تثبت هاتفًا أو WebGL أو Core Web Vitals. لم تُكتب أو تُشغّل اختبارات ميزات الخطة غير المبنية.
