# ضيوفي — لغة الواجهة

Arabic is the primary interface. Keep one term per concept; phone numbers, codes and mixed English names use LTR isolation. Counts distinguish people from invitations.

| Concept | Preferred Arabic | Usage |
|---|---|---|
| Owner home | مناسباتي | Personal collection, not analytics dashboard |
| Create | مناسبة جديدة / ابدأ تجهيز [النوع] | Choice then essentials |
| Event overview | المناسبة / نظرة عامة | Phone label / desktop destination |
| Invitation design sections | المحتوى · الشكل · التجربة · المناسبة | Event details are separately saved and affect the event |
| Save | تعديلات لم تُحفظ بعد / جارٍ الحفظ… / تم الحفظ / تعذر الحفظ | Inline, with retry on failure |
| Publish | مسودة لم تُنشر / منشورة / تعديلات غير منشورة | Guests see the last published snapshot |
| Sharing | افتح الرسالة في واتساب / نعم، أرسلته / تم التواصل يدويًا | Composer is not delivery proof |
| Delivery | جاهزة / تمت المشاركة / فُتحت / تعذر الإرسال | Separate from RSVP; retain platform/manual/simulated source |
| Reply | بانتظار الرد / أكد الحضور / اعتذر | Decline is neutral, not an error |
| Guests | قائمة الضيوف / الردود والمتابعة | Two views of one invitation-party model |
| Import | راجع الأسماء / تعديل الأعمدة | Resolve duplicates before adding |
| Seating | الطاولات / اختر لهم طاولة | Avoid technical assignment jargon in primary flow |
| Gate | الاستقبال / الوصول | Arrival distinct from RSVP and account login |
| Closure | بعد آخر ضيف / رسالة الشكر | Actual counts, no exaggerated success statement |
| Simulation | (محاكاة) | Required for automatic send/remind/thank-you and scan demo |

Do not say a message was sent merely because a link was opened. Do not say every guest arrived if only part of a family was checked in. An invitation may include several people; always name the unit beside a count.
