## مرجع النسخة وقرارات التنفيذ

- أساس العمل `main@bd6000a`. مقارنة تاريخ Git أثبتت احتواءه على `v2/final` و`audit/final-phase` و`feat/card-collection` و`feat/v2-ux-craft` و`codex/p01-gesture-stability`؛ لم نخلط نسخًا أقدم فوق النسخة المجمّعة.
- المطلوب بروتوتايب يمكن تجربة مساراته كاملة. WhatsApp وSMS يفتحان الرسالة للمستخدم؛ الدفع والإرسال الآلي وGoogle Wallet محاكاة معلنة. لا توجد عملية خصم أو إرسال آلي حقيقية.
- العربية المودرن افتراضية، مع المصري والسعودي كتفضيل مستقل للحساب. لا يعاد تحرير النصوص التي كتبها المستخدم.
- إنشاء المناسبة كان بالفعل خطوتين. الهدف تحسين ترتيب القرارات والمعاينة، والحفاظ على قلة الخطوات.
- فحص Vercel وجد مشروعين. المشروع الأحدث `doyofy-studio-laf2` مرتبط بالنسخة المجمّعة؛ التغييرات تراجع في فرع مستقل قبل الدمج.

## خطة التنفيذ ومعايير الإغلاق

| المتطلب | التنفيذ القابل للمراجعة | معيار القبول |
| --- | --- | --- |
| تكبير كروت الهيرو والمحرر | نسب متجاوبة، لوحة محرر تبدأ بارتفاع صغير، تكبير المعاينة | الاسم والتصميم أوضح، مع بقاء الأزرار متاحة على 320 و390 بكسل |
| استعراض مثل TikTok | سكرول رأسي بنقاط توقف وتحكم بالكيبورد وأزرار، وتحميل الفن المجاور فقط | التصفح لا يطبق التصميم؛ التطبيق يحتاج إجراء واضح |
| مشاركة التصميم | رابط عام يفتح التصميم المختار في إنشاء مناسبة | يعمل بدون مناسبة محلية سابقة، ويحافظ على اختيار المستخدم |
| ضبط البداية والمعاينة | معاينة البداية كاملة، ومسودة الإنشاء تعرض استكمالًا أو تجاهلًا | لا يفقد المستخدم البيانات عند التحديث؛ النشر يحفظ آخر تفاصيل صحيحة |
| خطوات أقل | خطوتا إنشاء، إعدادات ثانوية قابلة للفتح، إجراء أساسي حسب الحالة | لا إضافات لمجرد استكمال الـwizard؛ لا ازدحام للقنوات والإجراءات النادرة |
| مشاركة فردية وجماعية | WhatsApp وSMS ونسخ ومشاركة الجهاز داخل نفس قائمة المستلمين | فتح تطبيق لا يعني إرسالًا؛ التقدم محفوظ ولا يفقد الأرقام الناقصة |
| إجراءات الضيف الذكية | نشر/إكمال رقم/مشاركة/تذكير/اختيار طاولة/وصول/تفاصيل | المؤكد والمعتذر والواصل لا يعرض لهم نفس الإجراء الأساسي |
| الأدوار والطعام | صاحب المناسبة، المنظم، مزود الضيافة | الطعام لمزود الضيافة؛ عرض الضيافة للقراءة دون إدارة الدعوات |
| الفصل البصري | حالات وحدود ونصوص، مع مجموعات الطاولات وخريطة مستقلة | اللون عامل مساعد، واسم الضيف والطاولة والسعة قابلون للقراءة |
| سحب الضيوف والطاولات | نقل عائلات، ترتيب طاولات، بدائل بالأزرار والكيبورد | حفظ الترتيب؛ إلغاء السحب لا ينقل؛ مراجعة تجاوز سعة الطاولة |
| تصدير ملف | الظاهر أو المحدد أو الكل أو طاولات أو أقسام | CSV عربي يفتح في Excel، وعدد مطابق للنطاق، وحماية من صيغ الخلايا |
| نقل بين المناسبات | نسخ افتراضي ونقل بعد تأكيد، مراجعة التكرار والسعة | لا كتابة جزئية؛ روابط جديدة وردود وطاولات مستقلة؛ الواصل لا يُنقل |
| QR | بطاقة دخول بعد تأكيد دعوة شخصية، وتكبير الرمز | لا QR للمعتذر أو الرابط العام؛ الرد المحمول معزول عن بيانات المنظم |
| Google Wallet | معاينة بطاقة بعد التأكيد توضح حدود التجربة | لا ادعاء بالحفظ الفعلي، مع اسم المناسبة والضيف والتاريخ ورمز الدخول |
| حد الضيوف والدفع | سعة تشمل المرافقين، محاكاة نجاح وفشل وإلغاء | لا إضافة قبل الترقية؛ الإلغاء يحفظ المدخلات؛ النجاح يستأنف مرة واحدة |
| صوت الحساب | رفع ومعاينة وحذف وافتراضي، واختيار في التصميم | نوع وحجم صالحان، حفظ بعد التحديث، بدء بعد تفاعل وكتم فعّال |
| العربية والمصري والسعودي | تفضيل مستمر ونصوص الأفعال والمشاركة | يظهر التغيير فورًا؛ لا يتغير المحتوى الذي كتبه المستخدم |
| الإيماءات | تلميح قصير، بديل ظاهر، احترام تقليل الحركة | لا تعتمد مهمة على اكتشاف السحب وحده |

## حدود التكامل الحقيقي

| الخدمة | ما يقدمه البروتوتايب | ما يحتاجه التشغيل الحقيقي |
| --- | --- | --- |
| WhatsApp / SMS | رسائل مجهزة يرسلها المستخدم، وقائمة متابعة؛ محاكاة إرسال باسمها | مزود رسائل، موافقات القناة، تقارير تسليم، وحدود إرسال وإعادة محاولة |
| الدفع والباقة | سعة ودفعة وقيم تجريبية محفوظة على الجهاز | Checkout من المزود، webhook متحقق، entitlement من الخادم، ومعالجة منع التكرار |
| Google Wallet | معاينة كاملة لبطاقة الدخول | حساب إصدار، بطاقة موقعة من الخادم، وروابط إضافة حقيقية |
| الصوت | مقاطع محلية، حتى 3 × 300 كيلوبايت، ومشغل وكتم | تخزين ملفات وروابط تخدم أجهزة الضيوف؛ الروابط التجريبية لا تحمل الملف الصوتي |
| الردود وQR والأدوار | رحلة محلية قابلة للتجربة وروابط تحمل دعوة محمولة | API مشترك، تحقق من هوية وصلاحية الرموز، وصلاحيات مفروضة في الخادم |

عبارات البروتوتايب تشرح الحدود قرب الإجراء ذي الصلة. تقارير الاختبارات في [التحقق](verification.md) تميز اختبارات الدوم والسلوك عن فحص المتصفح والأجهزة الفعلية.
